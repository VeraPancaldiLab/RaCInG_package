# Read a RaCInG simulation output file

Read a RaCInG simulation output file

## Usage

``` r
Read_Sim_Output(filename)
```

## Arguments

- filename:

  Path to a `.out` file generated by
  [`runSim()`](https://VeraPancaldiLab.github.io/RaCInG_package/reference/runSim.md).

## Value

A list containing the average values, standard deviations, and raw
counts (one slice/row per patient, in file order), and `patients`, the
patient numbers (row indices of the simulated `Cmatrix`) of those
slices.
